执行摘要 · Executive Summary
以「划船 / 单车」有氧老用户低成本起量,跑步 / HIIT 人群作力量转化扩量,双画像分轨切入无氧赛道。

主推「一台全家健身房 · 独练也安心」融合最大众的全家叙事与安全卖点;价值排序为全功能 › 完整动作行程 › 商用级安全 › Pop-Pin;核心价格带 $1,299–1,799(主力 SKU ~$1,799),高配锚点 ~$2,499 衬托性价比;首发主阵地为品牌官网 DTC,Amazon 承接泛人群比价。

四项结论
01 — 首发种子人群与内容起手序

从划船 / 单车老用户切入,跑步 / HIIT 扩量

  • 低成本起量种子 = Merach 划船 / 单车有氧老用户:划船机老用户中 76% 是 Merach 有氧用户、85% 有力量目标、41% 高频训练,存量激活、获客成本最低。
  • 力量转化扩量种子 = 跑步 / HIIT 人群:54% 高频、54% 有 Smith 经验、95% 有力量目标,转化潜力全场最高。
  • 内容起手序:PM2 专业 › PM1 家庭 › PM3 泛运动。先以专业运动标杆树立信任,再用家庭叙事走量,泛运动承接。
PM2 专业(专业运动标杆:商用级强度对标 · 专业 / 进阶运动员实练背书)→ PM1 家庭(规模放量:最大 TAM 85% + 最强信息「全家健身房」)→ PM3 泛运动(健康 / 减脂广覆盖)
02 — 主 Slogan 与价值 / 参数优先级

主打「全家 + 安全」,参数按信任度排布

  • 主 Slogan:「一台全家健身房 —— 完整训练,独练也安心」。专业运动标杆专用「商用级安全 · 练到力竭也安心」。
  • 价值点优先级:① 全功能 All-in-One › ② 完整动作行程 › ③ 商用级安全 › ④ Pop-Pin 7°。经验越深越看重 Pop-Pin 与安全。
  • 参数凸显序:质保 & 耐久 → 框架稳定(3×3″ 立柱 + 跌落测试)→ 完整行程 → 配件生态(对专业)→ 7° Pop-Pin。
通用层打全功能 + 安全;进阶 / 专业层叠加 Pop-Pin 人体工学 + 配件生态(经验组信心 +27pp)。
03 — 价格带 / 区间 / 价格锚

主力 ~$1,799,高配锚 ~$2,499,入门钩 <$1,299

  • 核心价格带 $1,299–1,799:32% 集中,≤$1,799 累计 64%,主力 SKU 定位 ~$1,799。
  • 溢价层 $1,800–2,299:约 25% 愿付;有经验 38% / 跑步机老用户 42% / 男性 43% 更高。
  • 价格锚点:设高配「全套」锚点 ~$2,299–2,799,衬托主力性价比并吃溢价人群;入门钩 <$1,299(配件 / 分期)承接价格敏感 32%。
三档结构:入门钩 <$1,299 · 主力 $1,799 · 锚点 $2,499。
04 — 渠道偏好与人群特色

官网 DTC 为首发主阵地,Amazon 承接泛人群

  • 品牌官网 DTC = 主阵地:全样本 52%,专业 68% / 有经验 62% 更高,利润高、便于会员与高客单承接。
  • Amazon:16%(女性 19% 更高),靠评分 / A+ / Prime 承接比价型与泛运动人群。
  • 渠道未定 32%:用品牌内容与真实家庭场景种草,引导回 DTC。
首发资源压 DTC 官网(专业 + 经验人群集中);Amazon 作放量与泛人群承接位。
